# Hosting partner: EU Gamehost

![EU Gamehost]({{ "/assets/eugamehost-partner.png" | relative_url }})

**EU Gamehost is a partnered and recommended hosting provider for Dauntless Revived.** This is partner/promotional content, not an independent hosting benchmark.

Our own measurements are the basis for the recommendations: Ramsgate uses about **1.1 GB RAM**, a hunt server about **0.9 GB**, the Training Dojo about **0.9 GB**, and the Node control plane about **130 MB**. Our light-load estimate with every default hunt port active is roughly **9.5 GB** including a client on the host. Combat CPU load at scale is not fully measured yet.
